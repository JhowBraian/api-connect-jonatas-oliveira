# API Connect - Gerenciamento de Usuários (MVP)

## 📌 Objetivo do Projeto
A **API Connect** é uma solução back-end desenvolvida como um Produto Mínimo Viável (MVP) no formato de API RESTful. Seu objetivo principal é fornecer uma interface padronizada e segura para o gerenciamento de usuários (listagem, consulta unitária, criação, atualização e remoção), implementando separação de responsabilidades (SoC), persistência em memória e validação estrita de dados via JSON.

---

## 🚀 Tecnologias Utilizadas
- **Linguagem:** Python 3.x
- **Framework:** Flask
- **Manipulação de Requisições:** Flask Request & Jsonify
- **Controle de Versão:** Git & GitHub
